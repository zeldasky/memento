## 남은 위험 · 출시 전 할 일

1. **오픈소스 고지 화면** — MIT · Apache 2.0 은 배포물에 저작권·라이선스 문구를 넣어야 한다. 설정 아래 "오픈소스 라이선스" 화면을 만든다.
2. **MET Norway 사용량** — 약관상 앱 전체 합쳐 초당 20건을 넘으면 별도 협의, 그리고 "모바일 앱은 API 를 직접 부르지 말고 캐시 프록시를 두라"고 권한다. 저사용량은 직접 호출 허용. 사용자가 늘기 전에 작은 캐시 서버(예: Cloudflare Worker)를 앞에 둔다.
3. **개인정보** — 날씨를 받을 때 이용자의 대략 위치(소수 셋째 자리 ≈ 100m)와 IP 가 MET Norway 로 간다(MET 가 기록). 앱은 위치를 기기 밖 다른 곳에 저장·전송하지 않는다. → 개인정보 처리방침 URL, Play 데이터 보안 양식("대략적인 위치 — 앱 기능, 제3자 공유: 날씨 제공처")에 적는다. 권한은 `ACCESS_COARSE_LOCATION` 하나(정밀·백그라운드 위치 없음).
4. **앱 이름 "메멘토"** — 같은 이름·비슷한 이름 앱(Memento Database, Memento Mori Life Calendar 등)이 있고 영화 제목이기도 하다. 출시 전 KIPRIS 상표 검색과 Play·App Store 검색. 부제(예: "메멘토 — 남은 시간을 느끼는 시계")로 구분하는 방안.
5. **패키지 ID** — `io.github.zeldasky.memento` 는 출시 후 못 바꾸므로 바꿀 거면 첫 출시 전에.
6. **아이디어 자체** — "남은 인생 시각화(memento mori, life in weeks)" 앱은 이미 많다. 아이디어는 보호 대상이 아니고, 우리 그림·문구·코드는 자체 제작이라 문제 없음. 다른 앱의 화면·문구를 베끼지 않는다.
7. **iOS** — 같은 코드(Capacitor)로 빌드. Mac + Xcode 필요, Info.plist 에 위치 사용 문구(NSLocationWhenInUseUsageDescription).
