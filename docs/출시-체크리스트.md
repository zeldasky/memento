## 사용자가 할 일 (순서대로)

1. **플레이 콘솔 개발자 계정** — https://play.google.com/console , 등록비 $25(한 번). 신분증 · 전화번호 인증. 개인 계정이면 아래 3번(비공개 테스트)이 필수, 조직 계정(D-U-N-S 번호 필요)은 면제
2. **앱 만들기** — 이름 · 언어 · 무료 · 선언 체크 → "앱 콘텐츠" 설문(listing.md 답) → 스토어 등록 정보 붙여 넣기
3. **비공개 테스트** — 테스터 **12명이 14일 연속** 참여해야 프로덕션 신청이 열린다(2023-11 이후 개인 계정). 테스터 이메일 목록(구글 그룹이나 이메일 목록) 준비, AAB 올리기 → 초대 링크 공유 → 테스터가 설치하고 가끔 써 줘야 한다
4. **프로덕션 신청** — 14일 뒤 설문(테스트 소감 등) → 심사(보통 수일)

## 출시 전에 더 보면 좋은 것

- [ ] 앱 이름 상표 — KIPRIS 에서 "메멘토"(9류 · 42류) 검색, 플레이에서 같은 이름 앱 확인
- [ ] 실기기 점검 — 폴드8 접은 · 펼친 화면, 상태 표시줄 겹침, 끌기 · 누르기
- [ ] 패키지 ID `io.github.zeldasky.memento` 확정(출시 뒤 못 바꿈)
- [ ] 버전 올리는 법: package.json version → `npm run android:aab` (versionCode 는 자동, 올릴 때마다 커져야 함)
- [ ] MET Norway — 사용자가 늘면 캐시 서버(약관 권장)
- [ ] iOS — Mac + Xcode, Apple 개발자 프로그램 연 $99
