# 화면 보호기 — 무엇이고, 어떻게 동작해야 하나

메멘토 화면 보호기의 기준. 폴드8 같은 OLED(AMOLED) 화면을 전제로 한다.

## 1. 화면 보호기란

**화면을 켜 둔 채 아무도 만지지 않는 동안, 화면(패널)과 배터리를 지키면서 보기 좋은 것을 보여 주는 상태.**

- 원래 목적은 **번인(잔상) 막기**다. OLED 는 픽셀마다 스스로 빛을 내서, 같은 픽셀이 같은 밝기로 오래 켜져 있으면 그 픽셀만 먼저 늙어 자국이 남는다.
  - 고정된 요소(글자, 시계, 단추, 상태 표시줄, 로고)가 가장 위험하다.
  - 밝을수록, 오래 켤수록, 뜨거울수록 빨리 늙는다.
- 두 번째 목적은 **전력과 열**이다. 쉬는 동안까지 한창 쓸 때처럼 그리면 배터리를 쓰고 폰이 데워지는데, 열도 OLED 수명을 줄인다.
- 세 번째로 **사생활**을 지킨다. 자리를 비운 사이에 화면 내용이 드러나지 않아야 한다.

안드로이드에는 시스템 화면 보호기(**Dream, `DreamService`**)가 따로 있다. 폰이 **충전 중이거나 거치대에 꽂힌 채 쉬고 있으면** 시스템이 켜고, 만지면 끈다. 사용자는 「설정 → 디스플레이 → 화면 보호기」에서 어떤 앱을 쓸지 고른다.

## 2. 동작 원칙

| # | 원칙 | 하는 일 |
|---|---|---|
| 1 | **정지된 것이 없다** | 글 · 단추 · 시계 · 주제 이름을 모두 숨기고, 그림도 계속 자리를 옮긴다(픽셀 이동). 한 픽셀이 몇 분 넘게 같은 빛을 내지 않게 한다 |
| 2 | **대부분 검다(평균 밝기 낮게)** | 넓은 밝은 면(하늘색, 흰색)을 없애고 화면의 대부분을 꺼진 검정으로 둔다. 순백은 쓰지 않는다 |
| 3 | **밝기를 낮추고, 시간이 갈수록 더 낮춘다** | 처음엔 사용자가 정한 보호기 밝기로, 30분이 지나면 절반으로 더 어둡게 한다 |
| 4 | **아주 오래 두면 화면을 끈다** | 정한 시간(1시간 · 3시간)이 지나면 "켜 두기"를 풀어 시스템이 화면을 끄게 한다. 밤새 켜 두는 일을 막는다 |
| 5 | **덜 그린다** | 초당 60번 그리던 것을 15번으로 줄인다. 천천히 움직이는 그림은 그래도 매끄럽고, 전력과 열이 크게 준다 |
| 6 | **만지면 바로, 그대로 돌아온다** | 첫 손길은 깨우기만 한다(그 손길이 앱 안의 버튼이나 동작으로 이어지지 않는다). 깨면 원래 화면, 원래 밝기 |
| 7 | **중요한 일만 알린다** | 관심 주제에 특이 뉴스가 생기면 잠깐(30초) 밝게 장면을 보여 주고 다시 보호기로 돌아간다. 글자는 쓰지 않는다 |
| 8 | **시스템 화면 보호기로도 동작한다** | 앱을 열어 두지 않아도, 충전 중 쉬는 폰에서 시스템이 메멘토 보호기를 켠다(`MementoDream`) |

## 3. 메멘토에서 두 가지 길

| | 앱 안 보호기 | 시스템 화면 보호기(Dream) |
|---|---|---|
| 언제 | 메멘토를 연 채 「켜 두기」, 정한 시간(1 · 5 · 10분) 동안 손대지 않으면 | 충전 중 · 거치대에서 폰이 쉬면(시스템 설정 시간) — 메멘토를 열지 않아도 |
| 켜는 곳 | 메멘토 설정 → 화면 | 폰 설정 → 디스플레이 → 화면 보호기 → 메멘토 |
| 뉴스 장면 | 됨 | 아직 안 됨(앱 밖이라 뉴스를 받지 않는다 — 나중에 서버가 생기면) |
| 날씨 | 됨 | 저장된 위치로 됨 |
