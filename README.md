# 메멘토 — 남은 시간을 느끼는 앱

지금 나이와 "이만큼 살 것 같다"는 나이를 넣으면, 인생을 얼마나 지나왔는지 **정확한 숫자 대신 느낌으로** 보여 주는 앱.
배경은 고른 주제에 맞는 기하 도형·선의 움직임이고, 그 그림 자체가 지나온 만큼을 나타낸다.

안드로이드 · iOS 공통(Capacitor 8). 안드로이드 먼저. 스토어 배포 예정 — 라이선스 검토는 [docs/라이선스-검토.md](docs/라이선스-검토.md).

## 빌드 · 설치

```
npm install
npm run android:apk        → release/memento-<버전>.apk (디버그 서명, 시험 설치용)
adb install -r release/memento-<버전>.apk
```

필요한 것: Node, JDK 21, 안드로이드 SDK. 아이콘·시작 화면을 다시 그릴 때는 `npm run icons`(Python + Pillow + numpy).

## 느낌 문장

| 문장 | 예 |
|---|---|
| 인생을 하루로 치면 | 낮 1시 20분 무렵 (10분 단위) |
| 얼마나 왔나 | 5분의 3에 조금 못 미치게 왔어요 |
| 계절로는 | 초가을 (12칸) |
| 남은 것 (번갈아) | 앞으로 맞을 여름 약 38번 · 보름달 약 470번 · 주말 약 2,000번 … (두 자리로 뭉갬) |

설정에서 "숫자도 보기"를 고르면 나이·퍼센트·남은 햇수가 한 줄 더 나온다.

앱을 열 때 · 화면을 껐다 다시 볼 때마다 **비유가 바뀐다**(`www/js/metaphors.js`, 21가지, 최근에 본 것은 피함):
하루 시계 · 1년 달력 · 24절기 · 사계절 · 300쪽 책 · 마라톤 · 축구 · 야구 · 영화 · 노래 · 서울→부산 KTX · 100층 빌딩 · 배터리 · 피자 · 초 · 일주일 · 등산 · 서울→뉴욕 비행 · 피아노 88건반 · 커피 한 잔 · 3박 4일 여행.
위쪽 문장은 한 번에 한 문장 — 비유 → 한마디 → 남은 것이 약 6초마다 스르륵 바뀐다. 문장을 누르면 다른 비유로 바뀐다.

## 화면

- 열 때 · 주제를 바꿀 때: **「와」 넘어가기** — 어두워지고 빛줄기가 쏟아지는 동안 나이가 0세 → 지금으로 오르고, 섬광과 함께 지금의 그림이 드러난다
- 설정 「화면」: 켜 두기(@capacitor-community/keep-awake) · 밝기(앱 창 밝기, screen-brightness — 브라우저에서는 검은 막) ·
  화면 보호기(손대지 않고 1 · 5 · 10분 → **번인 막기**: 화면 대부분을 검게 끄고, 그림은 작은 둥근 창 안에만 — 그 창이 약 10분 주기로 화면 곳곳을 떠돈다. 글 · 단추 같은 고정 요소 없음. 누르면 돌아옴)
- **시스템 화면 보호기**(`MementoDream`, 안드로이드 DreamService): 충전 중 · 거치대에서 쉬면 앱을 열지 않아도 시스템이 켠다 —
  폰 설정 → 디스플레이 → 화면 보호기 → 메멘토. 앱 설정은 MementoBridge 로 안드로이드 저장소에 적어 두고 Dream 이 읽는다.
  보호기 원칙(픽셀 이동 · 대부분 검게 · 초당 15번 · 30분 뒤 더 어둡게 · 1/3시간 뒤 끄기)은 [docs/화면보호기.md](docs/화면보호기.md)
- 주제는 3칸 — 칸마다 [글자로 | 아이콘으로](아이콘: 그림 7 + 기하 무늬 8, `www/js/icons.js`), 동그라미로 고른 **메인**이 그림이 된다.
  글자로 넣은 주제는 뉴스 특이점 대상. 위쪽 칩은 메인 + 나머지 수(+2)
- 처음 설치하면 가이드 카드 7장(`www/js/guide.js`) → 설정. 위쪽 도움말(?) · 설정 아래 「도움말」로 다시 본다

## 뉴스 특이점 (시험판)

관심 주제의 기사가 평소보다 몰리거나 논조가 뚜렷한 낱말(어닝 서프라이즈 · 어닝 쇼크 · 급등 · 리콜 …)이 몰리면(`www/js/signal.js`)
화면을 밝히고 **30초 동안 글자 없는 장면**으로 알린 뒤 원래 화면 · 밝기로 돌아온다(`www/js/events.js`, 누르면 바로 끝).
좋은 소식 7: 로켓 발사 · 불꽃놀이 · 풍등 · 해돋이 · 꽃이 핌 · 열기구 · 치솟는 그래프 / 나쁜 소식 6: 유성 추락 · 폭풍우 · 유리 깨짐 · 소용돌이 · 곤두박질 그래프 · 해넘이 /
논조가 불분명한 큰 뉴스: 혜성. 최근에 나온 장면은 피한다. 장면 동안은 인생 문장 · 주제 이름도 숨긴다(옆 사람이 봐도 그림뿐).
뉴스 출처는 갈아 끼운다(`www/js/news.js` 의 `M.newsProvider()`):
- **디버그 빌드(내 폰 시험)**: 구글 뉴스 RSS — 화면이 보이는 동안 20분마다 글자 주제를 받아 기기에 7일치 쌓고, 최근 3시간 기사 수를 평소 3시간 평균과 비교.
  같은 주제는 6시간에 한 번만. 구글 피드 약관이 "개인 · 비상업 피드 리더"만 허용하므로 **출시판(release)에서는 자동으로 꺼진다**
- **나중(출시)**: 우리 서버가 계약한 출처(딥서치 · 빅카인즈 등)에서 받아 준다 — `MEMENTO_NEWS_SERVER=주소 npm run android:aab` 로 빌드하면
  `GET {서버}/v1/headlines?topic=…` → `[{t, h}]` 를 쓴다
- 설정의 미리보기 · `?news=surprise|shock|notice` 로 시험용 제목 묶음도 돌려 볼 수 있다

## 손가락

- 좌우로 끌기: 그 나이의 나 — 그림 · 비유 · 인생 줄이 손가락 자리로 바뀐다(타임머신). 놓으면 지금으로 돌아온다
- 누르기: 물결과 불티가 퍼진다

## 오래 보아도 되풀이되지 않게

그림 속 비율 · 색 · 기울기는 몇 분 단위로 흐르는 느린 잡음(`U.drift`)을 따르고, 별똥별 · 돌풍 같은 일은 무작위 간격(`U.every`)으로 일어난다.
기하 무늬는 일곱 가지(진자 · 나선 꽃 · 장미 곡선 · 겹 도형 · 씨앗 배열 · 물결 간섭 · 3차원 매듭)가 2~4분마다 9초에 걸쳐 겹쳐 바뀐다.
시험할 때는 주소에 `?t=초`(그 시각의 모습) · `?news=surprise|shock|notice` · `&scene=rocket&et=12`(장면 · 12초째) · `?saver=1`(바로 화면 보호기) · `?topics=삼성전자,@rose&main=1` · `?guide=1`(가이드)을 붙인다.

## 주제

주제 칸에는 아무 낱말이나 쓸 수 있다. 아래 낱말이 들어 있으면 그 그림으로, 없으면 낱말 글자로 무늬와 색을 뽑는다(같은 낱말이면 늘 같은 무늬).

| 주제 | 알아듣는 낱말(일부) | 지나온 삶을 나타내는 것 | 오늘을 반영 |
|---|---|---|---|
| 날씨 | 날씨, 하늘, 구름, 비, 눈 | 하늘을 가로지르는 해 | 지금 날씨(하늘색·구름·비·눈·번개·안개, 바람), 땅 위 줄 = 이번 주 7일 |
| 달 | 달, 보름달, 달빛 | 달을 두른 고리 | 오늘 진짜 달 모양 · 보름까지 며칠 |
| 우주 | 우주, 별, 밤하늘, 행성 | 내 궤도에 그은 선 | — |
| 바다 | 바다, 파도, 물결 | 배가 건너온 물길 | — |
| 나무 | 나무, 숲, 꽃, 낙엽 | 잎 색(봄 꽃 → 초록 → 단풍 → 낙엽) | — |
| 계절 | 계절, 봄, 여름, 가을, 겨울 | 사계절 바퀴 | 바깥 계절(꽃잎·반딧불·낙엽·눈), 올해 위치 |
| 모래시계 | 모래시계, 시간, 모래 | 아래 쌓인 모래 | — |
| 그 밖의 낱말 | 커피, 음악, 가족, 비트코인 … | 밝게 그린 만큼(나선 꽃 · 물결 · 겹 다각형 · 씨앗 배열) | — |

날씨는 MET Norway(노르웨이 기상청, CC BY 4.0) 자료. 위치는 폰의 대략 위치, 권한을 안 주면 서울. 설정에서 앱 안 도시 목록으로 고정할 수 있다.

## 구조

```
www/                화면(앱에 그대로 들어간다)
  index.html          뼈대 · 설정 창
  css/style.css
  js/core.js          도구 · 인생 계산 · 느낌 문장 · 주제 등록/고르기
  js/cities.js        날씨 위치용 도시 목록
  js/themes/*.js      주제 하나에 파일 하나 (index.html 의 script 순서 = 낱말 겹칠 때 우선순위)
  js/app.js           설정 저장(localStorage) · 위치 · 날씨 불러오기 · 그리기 고리
  fonts/              빌드 때 scripts/copy-fonts.mjs 가 채운다(저장소에 안 넣음)
android/            Capacitor 안드로이드 프로젝트
scripts/            make-apk.mjs · copy-fonts.mjs · make-icons.py
store/              스토어용 아이콘(512) · 그래픽 이미지(1024x500)
docs/               라이선스 검토
```

새 주제는 `www/js/themes/` 에 `M.registerTheme({ id, name, story, keywords, create(env) { return { resize, draw, caption } } })` 꼴로 파일을 만들고 `index.html` 에 script 한 줄을 넣으면 된다. `draw(g, { t, dt, p, now })` 의 `p` 가 지나온 비율(0~1).
