날씨 위치
화면

보호기 그림 — 남들 눈엔 무늬, 나에겐 내 나이: 나이테(산 해만큼) · 10년 도형(지나온 10년마다 하나) · 별자리(산 해만큼 이은 별) · 인생의 달(초승→보름→그믐) · 인생 시계

화면 보호기는 화면(번인)과 배터리를 지켜요. 손대지 않으면 글을 모두 지우고, 화면 대부분을 끈 채 작은 그림 창만 화면 곳곳을 천천히 떠돌아요. 30분 뒤엔 더 어둡게, 정한 시간이 지나면 화면을 꺼요. 누르면 돌아와요. 관심 주제에 특이 뉴스가 생기면 30초 동안 글자 없는 장면으로 알려요.
충전 중에는 앱을 열지 않아도 쓸 수 있어요: 폰 설정 → 디스플레이 → 화면 보호기 → 메멘토

진짜 뉴스는 아직 안 받아요. 저장하면 시험용 기사 제목으로 30초짜리 장면을 바로 틀어요(글자는 안 나와요). 누르면 끝나요.
